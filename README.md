# Sistema de Gestión de Solicitudes Académicas
Trabajo Práctico Integrador - Metodología de Sistemas II

## Descripción
Sistema de consola para administrar el ciclo de vida de trámites estudiantiles. Permite registrar, clasificar y transicionar los estados de las solicitudes operativas.

## Tecnologías Utilizadas
* Python 3.10
* Persistencia simulada en memoria (Listas y Diccionarios)

## Instalación y Ejecución
1. Clonar el repositorio: `git clone <URL>`
2. Ejecutar el archivo principal: `python main.py`

## Funcionalidades
1. Registrar nueva solicitud.
2. Asignar responsable.
3. Actualizar estado y prioridad.
4. Generar reporte.
